Tài Liệu API: Endpoint /api/predict

Nhận diện và đếm số lượng học sinh bằng YOLO kết hợp Depth Anything V2 & Depth-NMS
1. Tổng Quan Endpoint
Đường dẫn (URL):
/api/predict
Phương thức (Method):
POST
Content-Type gửi:
multipart/form-data
Định dạng trả về:
application/json (200 OK)
2. Dữ Liệu Đầu Vào (Request Form-Data)
Trường (Field) Kiểu (Type) Bắt buộc Mô tả
image File (Binary) Có Tệp hình ảnh phòng học cần nhận diện (.jpg, .jpeg, .png, .webp). Tệp không được rỗng và OpenCV giải mã được.

4. Các Mã Lỗi Thường Gặp (Error Codes)
Mã lỗi HTTP Tình huống xảy ra Chi tiết thông báo (detail)
400 Bad Request Tải lên file sai định dạng (không phải JPEG, PNG, WebP) "Invalid file type. Only JPEG, PNG, and WebP images are allowed."
400 Bad Request File tải lên không có dữ liệu (dung lượng 0 byte) "Uploaded file is empty."
400 Bad Request File bị hỏng, OpenCV không thể giải mã thành ảnh "Failed to decode image."
500 Internal Error Lỗi xử lý suy luận trong mô hình AI "Inference failed: <chi tiết lỗi>"
5. Ví Dụ Gọi API (cURL, Python, JavaScript) 
curl -X POST "http://localhost:8010/api/predict" \
  -H "accept: application/json" \
  -H "Content-Type: multipart/form-data" \
  -F "image=@data/samples/classroom.png;type=image/png"
